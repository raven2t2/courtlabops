## IDEA #2: Kanban Automation — "Coach Task Board" Feature for courtlabops
**Execution Time:** 3-4 hours | **Impact:** Medium (product differentiation, operational excellence)

### The Play
Add a **coach-facing task board** feature to `courtlabops.vercel.app` that automatically generates coaching action items from CourtLab drill data. Series B narrative: "We're not just data — we're coaching systems."

**Targets:**
- **Current users** (retention + feature adoption)
- **Free trial coaches** (conversion lever — free task automation)
- **Sponsors** (Easter Classic — position CourtLab as operational hub for events)

### Feature Brief

**What it does:**
Coach runs a drill → CourtLab extracts performance insights → Task board auto-generates:
- ✅ Assign individual drills to players (based on gaps)
- ✅ Schedule follow-up sessions
- ✅ Flag recruitment candidates (combine data)
- ✅ Sync with parent/player notifications (future)

**Current state:** Coaches use separate Kanban (Michael + Esther's admin board visible on courtlabops)
**New state:** Coaches get **their own task board** auto-populated from drill results

### Implementation (Code-Ready PR)

**1. Backend (1 hour):**
```javascript
// Endpoint: /api/coach/[coachId]/tasks/auto-generate
// Input: drillId, players[], performanceData
// Output: taskBoard[] with suggested actions

const generateCoachTasks = (drill, players, performance) => {
  return [
    {
      id: uuid(),
      type: "individual_drill",
      player: player.name,
      title: `Follow-up: ${drill.name} — ${performance.area}`,
      description: `Player scored ${performance.score}% on ${performance.metric}. Recommended: 3x15min sessions this week.`,
      dueDate: addDays(today, 3),
      priority: performance.score < 60 ? "high" : "medium",
      autoGenerated: true
    },
    // ... more tasks
  ];
};
```

**2. Frontend (2 hours):**
- Reuse existing Kanban component from courtlabops
- Add filters: by player, by date, by priority
- "Archive" button for completed tasks
- Drag-and-drop to reschedule

**3. UI Integration:**
- New tab in Coach Dashboard: "My Task Board"
- Live badge: "3 new recommendations from drills"
- One-click "Assign to Team" for batch actions
